# OpenCode Safe

## How This Is Different From OpenCode

- OpenCode Safe is an independent fork and is not affiliated with the upstream OpenCode project.
- It is privacy-first by default: Zen Cloud integration, session sharing, and OpenTelemetry paths are disabled.
- The goal of this fork is to keep usage local and avoid sending data to OpenCloud services.
- Branding, release channels, and distribution references are maintained under `opencode-safe`.
